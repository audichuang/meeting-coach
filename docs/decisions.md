# 決定

依時間排列，後面的覆蓋前面的。2026-11-26 的交接規格見 tag `handoff-2026-11-26`。

## 沿用交接規格、仍然有效的

- iPad mini 優先，macOS 之後再說。
- 紙張是畫面主體：大紙面、浮動工具列；橫向時建議卡在旁、直向收成一行。手寫、看卡、按按鈕都不能影響錄音。
- 錄音、逐字稿、會後摘要是三個獨立成果，都要保留；即時建議是第四層。
- 建議卡六類：分歧、技術風險、弱論點、商業影響、共同目標、具體下一步。只能指向聽得到的話與時間段，不推斷人格、身份或意圖。
- 不保存聲紋、不跨會議認人（Kurn 原有功能已預設關閉）。
- 錄音回呼裡不做網路、資料庫或阻塞 I/O；斷線、中斷、磁碟不足要在畫面上看得到。
- 建議卡與互動都寫成 append-only 事件（`SuggestionLedger`）。

## 2026-11-27 第一輪

- **場景是多人實體會議**，iPad 放在現場收音。同機 Teams 音源、耳機路由不在範圍內；最大風險變成單一遠場麥克風收 3–4 人。
- **雲端使用與錄音已獲許可**，所以規格裡的公司核准關卡、`ConsentReceipt` 與企業端點前置都拿掉；仍保留錄音狀態的明示。
- **建議卡給可以直接說出口的一兩句話**，取代原本的「只給思考提示」；**收尾**給約 30 秒的口語整理。
- **會議語言是台灣華語夾英文**；benchmark 拿掉日語。
- **講者只用匿名標籤**，手動命名暫緩。
- **記憶與整理在 Claude Code 端做**：App 只負責產出匯出包，未來可能匯入 Claude Code 的記憶當會中脈絡。App 內的 `MemoryProposal`、`ContextImport` 審核流程取消。
- **順序**：先在 Mac 驗證 Gemini Live 能否輸出靜默文字卡，同時實際試用 Kurn，再動 iPad。
- **第一版範圍**：錄音、手寫紙面、建議卡、收尾，會後摘要沿用 Kurn。

## 2026-11-27 第二輪

- **本人標記納入第一版**：使用者可手動指出哪個講者標籤是自己；仍不辨識他人、不跨會議。
- **匯出走系統分享**（例如 AirDrop），匯出包的檔案格式之後再定。
- **Claude Code 記憶匯入仍在構想**，第一版不做。
- **手寫只是筆記**，不送 AI。
- **建議卡頻率**沿用 90 秒間隔、10 分鐘最多 3 張，可在設定調整。
- **Gemini key 第一版由使用者貼入、存 Keychain**；OpenRouter 不支援 Live 的 WebSocket 串流，不採用。給家人用時再評估 Google 的 ephemeral token。

## 2026-11-27 第三輪

- **會議最長約 2 小時**，錄音與 Gemini 重新接線都要撐過這個長度。
- **本人標記在即時逐字稿上做**：會中顯示即時逐字，點一句選「這是我」，該場整個標籤歸使用者，可改，不帶到下一場。
- **卡片回饋**：滑掉即忽略；展開後只有「有用」「不準」，紀錄保留供調 prompt。
- **斷網**：錄音與逐字稿照常；卡片區顯示 AI 暫停，恢復後重接，斷線期間不補送，只標缺口。

## 2026-11-27 第四輪（實測後定案）

- **AI 全部用 OpenAI**，不用 Gemini（見 ADR 0001）：即時逐字稿 `gpt-live-transcribe`、建議卡與收尾 `gpt-6.1-terra`、會後 `gpt-transcribe` 整段重轉產生正式逐字稿再出繁中摘要。簡轉繁在 App 端做；術語表保守使用。
- **建議卡改為事件觸發**：停頓、問句或點名、長獨白後才判斷要不要出；開場 2 分鐘不出；90 秒冷卻、10 分鐘最多 3 張。另有「我該說什麼」要卡按鈕，不受限制。
- **以 Kurn 改造**：保留錄音、當機復原、資料層、匯出，主畫面重做；第一版不含本機轉寫模型，斷網只錄音，會後重轉補齊。
- **花費**：畫面持續顯示本場花費；單場超過 US$10 跳警告，5 分鐘內沒按「繼續」就停止 AI 處理（錄音照常）。

## 2026-11-27 第五輪（v1 第一批實作後）

- **介面語言跟系統**，新增繁體中文（台灣）與日文；英文保留，Kurn 原有的其他語系不移除（新字串暫用英文）。
- **會議教練預設開啟**，錄音畫面持續顯示 Live 與花費。
- **按「繼續」後**，再多花一個門檻（預設 US$10）才再次警告。
- **之後不讓使用者自己填 API key**：規劃一層 Cloudflare 後端，為日後訂閱制做準備（設計待定案，見下一輪）。
