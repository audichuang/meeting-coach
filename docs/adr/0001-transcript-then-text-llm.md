# 0001：建議卡用「即時轉寫 → 文字 LLM」，不用原生音訊模型

日期：2026-11-27。狀態：採用。

交接時的既定方向是讓 Gemini Live 直接聽原音出卡。改變的原因是同一份 8 分鐘合成會議的盲評：即時轉寫接文字模型 3.85／5（完美逐字稿 4.15），Gemini 3.8 Live 原生音訊 3.36（新觀點最弱、漏掉整個議題），OpenAI Realtime 3.17（術語聽錯最多）。收尾也是文字模型最快、最正確（約 6 秒 vs Gemini 23.5 秒）。社群調查顯示同類產品幾乎都走轉寫加文字模型，且 Gemini 3.8 Live 長連線有每約 15 分鐘出錯、58 分鐘強制斷線、無法關閉「模型自行不回應」等回報。

取捨：放棄語氣、停頓等聲學線索；卡片品質受即時轉寫錯誤（約 15% 字錯率）拖累，所以轉寫模型與 prompt 要能替換。只依賴 OpenAI 一家，供應商風險集中。

限制：全部結論來自乾淨的 TTS 合成音檔與單一評審；真實會議室錄音需重測。Gemini 文字模型因測試 key 為免費額度而未公平比較。
